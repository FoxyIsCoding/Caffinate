# Caffinate :3 

a open-sourced app that allows you to track your stats and usage of Energy drinks.. As of now its in early beta but still something!

It can be either used for tracking your addicted energy drink usage orrr for a virtual Can collection :3

Feautures: 
- Add and remove cans
- Edit cans
- View cans
- Great segsy ui btw
- Export and backup cans
- Customizable in settings
- Track health and daily consumption!
